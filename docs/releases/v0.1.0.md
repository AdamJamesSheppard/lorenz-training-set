# v0.1.0 — Attractor-density neural pilot research snapshot

Release date: 2026-10-04

This first tagged research pre-release preserves the solver and bounded neural
pilot implementation. It is not production certification or evidence of neural
generalization. Earlier commits remain available in Git history.

## Changes since the previously published main branch (0a952b1)

- Add the editable solver monograph, evidence ledger and packaging/verification
  tools, including separate treatment of failed AFC scientific gates.
- Add a bounded six-law neural pilot using sampled deterministic Lorenz
  state-space densities without Gaussian fitting or observation channels.
- Add conservative learning-grid export, sample gates and trajectory-level
  splitting with a persistence comparator.
- Enable CUDA-preferred neural training and a dedicated GPU capability check.
- Repair roundoff-induced negative empirical initialization values using direct
  nonnegative-kernel convolution and add regression coverage.
- Document the density-only workflow, initialization failure and fresh restart.
- Use 2 GiB available-memory pause/resume thresholds. Pausing retains process
  memory; this mechanism does not provide checkpoint-based recovery.

## Scientific scope and limitations

The fixed-diffusion, fixed-horizon pilot learns exported discrete solver targets.
It does not implement a complete assimilation cycle. Recorded restart dispatch
is not a completed forecast or training result.

MFEM uniform equivalence is certified for the tested configuration. Mature-state
positivity/statistical gates and two tested aligned domain expansions pass.
Full mature-density continuum convergence remains open, and large-scale
production dataset generation remains unauthorized. Existing evidence does not
establish accuracy for every newly generated empirical initial law.
