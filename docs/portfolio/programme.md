# What the project is trying to do

The aim is to find out whether a learned model can forecast a full probability distribution well enough to support later Bayesian data assimilation. The work is split into stages because a model can only be assessed properly if its inputs, numerical targets and evaluation are suitable. The original six-case pilot showed that data generation and training could be joined together, but it also exposed problems with the predicted statistics. G00–G03 have scoped recorded passes; G04 reference applicability remains open, and later stages remain locked. The linked programme record gives the decisions, conditions and remaining deployment requirements.
