# What the project is trying to do

The aim is to find out whether a learned model can forecast a full probability distribution well enough to support later Bayesian data assimilation. The stages are intended to help check the inputs, numerical targets and evaluation before drawing conclusions about the model. The original six-case pilot brought data generation and training together, although its predicted statistics still need improvement. G00–G03 have scoped recorded passes; G04 reference applicability remains open, and later stages remain locked. The linked programme record gives the decisions, conditions and remaining deployment requirements.
