# What the pilot results show

The pilot produced training pairs and a trained model, allowing the prediction to be compared with both the numerical forecast and the unchanged initial distribution. On case 5, relative density L2 error improves from about 0.4710 for persistence to 0.3519 for the operator. Mean error and covariance error become worse, so the improved density score does not establish that the model preserves the statistics needed for inference. The original test case has since been inspected and cannot be treated as untouched evaluation for further development.
