# What needs to be recorded

For a new method or experiment, the project requires a record of what is being tested, where the method comes from, which assumptions apply and how the outcome will be judged. The resulting decision then needs to link back to the configuration, run, measured criteria and reviewer. This applies equally to successful, failed and incomplete work. The purpose is to make the reasoning followable and prevent a completed calculation from being mistaken for an accepted scientific result. REQ-RT-001 remains mandatory: missing traceability blocks qualification and promotion, and neither a citation nor a software test substitutes for scientific review.
